A Java-based Electricity Billing System designed to manage customers, electricity usage, billing and payment records efficiently.

# Features:
* Admin and Staff Login
* Add, Update, Delete and View Customer Information
* Manage Meter Information
* Add and Manage Meter Readings
* Calculate Electricity Consumption
* Generate Electricity Bills
* View Bills
* Manage Payment Records
* View Payment slip
* Admin and Staff Role-Based Access
